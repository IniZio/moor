# Area A: Task lifecycle (feature inventory for the moor rewrite)

Frozen source: `$REPOS/moor` at `b8e8801` (main). Read-only. Inputs: `GLOSSARY.md`, `docs/adr/0001-0005`, `README.md`, `skills/moor/SKILL.md`, `.groundwork/work/v1/spec.md`, `src/{task,sleep,pane,registry,surface,driver,crabbox,claude_bg,agent,provision,worktree,cli,env,hosts}.rs`, `tests/task_cli.rs`, `.groundwork/BACKLOG.md`, `.groundwork/work/v1/evidence/c4/usage-log.md` (cited as `UL-n`), `motive.md` decisions 21, 39.

Scope: `start`, `list`, `close`, `remove`, `open`, `steer`, `wait`, `pane`, `shell`, plus shared machinery (registry, queue, sleep/wake, Box acquire, setup, dotfiles, dispatch, transcript, teardown). `run`/`cp`/`report`/`gate`/`env`/`github`/`proxy` belong to other areas; they appear only where they feed lifecycle state (events `run_started`/`ran`, wake on `run`/`cp`, proxy start at box-agent launch).

Rows are Given/When/Then in user-observable terms. Parity is behavioural: CLI/JSON may be redesigned, so literal strings are quoted only where a fake or script can observe them. Observable via: stdout/stderr, exit code, registry rows/events (`moor pane --json`, or the SQLite file in the state dir), files under the state dir or worktree, argv/env received by the fake `crabbox`, `herdr`, `claude`, `ssh`.

Coverage: `bb:<test>` = black-box test in `tests/task_cli.rs`; `internal:<test>` = unit test inside `src/*.rs` only; `none` = no test. Flags: `KNOWN-BUG` (do not port; cited), `DESIGN-SMELL`. `(inferred)` = derived from reading code, not run.

Defaults: provider `local-container`, size `small`, `drivers.crabbox.sleep_after_minutes` 30, `max_boxes` unlimited, `ssh_port` 22, prompt window 8000 ms (`MOOR_AGENT_PROMPT_WINDOW_MS`), wait poll 1000 ms (`MOOR_WAIT_POLL_MS`), hook cache TTL 120 s, "starting" grace 120 s, hook read bound 20 s, setup tail 40 lines, dead-provisioning grace 120 s.

## Fakes: external processes and how `tests/task_cli.rs` stubs them

All fakes are bash scripts written per test into a `TempDir`, selected by env vars. Every `moor` call runs the real binary with `MOOR_STATE_DIR`, `XDG_CONFIG_HOME` (0755 dir), `MOOR_HERDR_BIN`, `MOOR_CRABBOX`, `MOOR_CONFIG`, `MOOR_AGENT_BIN`, `MOOR_AGENT_CONFIG`, `MOOR_AGENT_DAEMON_LOG`, `MOOR_AGENT_SETTLE_TIMEOUT_MS=5000`, `MOOR_AGENT_PROMPT_WINDOW_MS=0`, `MOOR_WAIT_POLL_MS=50`, `FAKE_CRABBOX_CHATTY=1`, cwd = a real `git init` repo with one empty commit.

| Process | Fake / real | Records and simulates |
|---|---|---|
| `git` | Real | Worktrees created by the fake herdr (`git worktree add -b`); `rev-parse`, `status`, `log`, `branch -D` on real temp repos. |
| `herdr` (`MOOR_HERDR_BIN`) | `FAKE_HERDR`, state dir `herdr/` | Appends `$*` to `herdr/log` and `herdr <args>` to shared `seq`. Handles `worktree create` (real `git worktree add -b`, writes `wts/<key>`, JSON workspace_id `ws-<key>`), `worktree list` (closed entries have `open_workspace_id:null`), `worktree remove`, `workspace create/close/rename`, `tab list` (always empty), `tab create` (new `p-N`, `root_pane.pane_id`), `pane list` (minus `gone-ids`/`pane-gone`), `pane close`, `pane read` (cats `pane-output-<pane>` or `pane-output`), `pane run/send-keys/send-text` (log only); anything else exit 0 (so `plugin pane open`, `workspace focus` succeed silently). Knobs: files `pane-gone`, `pane-output[-p-N]`, `next-pane-output`, `wts/<name>`. Not simulated: pane `agent_status` (always absent -> Unknown), any failure mode except a missing binary. |
| `crabbox` (`MOOR_CRABBOX`) | `FAKE_CRABBOX`, state dir `crabbox-state/` | Logs `$*` to `log` and `crabbox <args>` to `seq`. `warmup`: chatter, appends slug to `live`; knob `fail` -> exit 2 "quota exceeded for plan". `run`: strips to after `--`; a command containing `MOOR_WORKDIR` returns `MOOR_WORKDIR=/box/work`; knobs `run_fail_match` (exit 7), `run-sleep`; logs `SEED=$CRABBOX_SYNC_GIT_SEED_SOURCE`; then `exec "$@"` (the Box command runs locally on the host in the worktree). `cp`: writes `from:<src>` to dest; knob `cp_exit`. `tunnel`: prints `{"box":B,"host":H}` then sleeps 300. `list`: cats `list_json`. `stop`: logs `DELETE=$CRABBOX_NAMESPACE_DELETE_ON_RELEASE`; knob `release_fail` (exit 5); removes id from `live`, else prints "<provider> lease not found: <id>" exit 4. | `crabbox ssh` + `ssh` | `install_fake_ssh` wrapper + `FAKE_SSH` | `crabbox ssh ...` prints a quoted path to `fake-ssh`; it records argv in `ssh-calls` and runs the last argument with `sh -c` locally. Used by box credential, dotfiles, Box agent, hook read, probe tests. Hook reads hit the absent local path `/box/work/.moor/agent-state.json`, so hook sources are unreachable black-box. |

| `kill -0`, `tar`, `sh`, `pgrep` | Real | pid liveness, dotfiles upload, shell. |

Suite-design implications: the fake `crabbox run` executes Box commands on the host, so dotfiles/teardown/transcript scripts really run in the worktree cwd and may touch host `$HOME`; isolate `HOME` in a hermetic parity suite. There is no clock fake, so idle grace (120 s), sleep_after (minutes) and hook cache TTL are testable black-box only via `sleep_after_minutes: 0`, editing the SQLite file, or internal tests.
